## 2026-07-20 - Adding ARIA Labels to Responsive and Icon-Only Interactive Elements
**Learning:** When using responsive elements where visible text is hidden on smaller screens via Tailwind classes (e.g., `hidden lg:inline`), or when buttons only contain structural icons (e.g., `<span class="material-symbols-outlined">`), screen readers lose the context on those smaller screens or altogether. Additionally, screen readers may read out the raw icon ligature (e.g., "rocket launch" or "arrow back") instead of the intended action name.
**Action:** Always ensure the parent interactive element (`<button>` or `<a>`) has an explicit `aria-label` attribute to maintain a consistent accessible name across all viewport sizes. Furthermore, add `aria-hidden="true"` to structural icon elements within these interactive elements to prevent screen readers from reading raw ligatures. Crucially, before applying `aria-hidden="true"` to an icon, verify its parent interactive element has an accessible name; otherwise, the interactive element becomes invisible to screen readers.
