## 2024-07-28 - [Accessible Icon Buttons & Responsive Hidden Text]
**Learning:** When using responsive utilities (e.g., `hidden sm:inline`) on button text, screen readers may fail to announce the button's purpose on smaller viewports. Furthermore, raw Material Symbols ligatures (e.g., `rocket_launch`) without `aria-hidden="true"` can be announced confusingly by screen readers. However, adding `aria-hidden="true"` to an icon without ensuring its parent interactive element has an accessible name (via `aria-label` or visible text) renders the element completely invisible to assistive technologies.
**Action:** Always add an explicit `aria-label` to interactive elements containing responsive hidden text or icon-only content. Add `aria-hidden="true"` to structural icon elements (`<span>` or `<i>` for font icons/ligatures) to prevent screen readers from reading the raw ligature text, but *only* after confirming the parent has an accessible name.
