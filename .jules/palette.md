## 2024-07-22 - Accessibility Issue: Interactive elements losing accessible names due to responsive classes
**Learning:** When using responsive Tailwind classes (like `hidden lg:inline`) to hide visible text on smaller screens within interactive elements (buttons, links), the element can lose its accessible name for screen readers if it only contains an icon. This happens because the screen reader might not read the hidden text, making the button "icon-only" and inaccessible.
**Action:** Always ensure that if visible text is hidden responsively, the parent interactive element (button or link) has a persistent `aria-label` to maintain its accessible name across all screen sizes. Also, add `aria-hidden="true"` to the structural icon elements (like `<span class="material-symbols-outlined">`) to prevent screen readers from reading the raw ligatures, but ONLY if the parent has an accessible name.
