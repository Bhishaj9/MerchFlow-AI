## 2025-05-05 - Accessibility of Responsive Buttons and Material Symbols
**Learning:** Responsive interactive elements with text hidden on smaller screens (e.g., using `hidden lg:inline` from Tailwind) must retain an explicit `aria-label` on the parent (`<button>` or `<a>`) to remain accessible, as the text is effectively invisible to screen readers on those viewport sizes. Additionally, Material Symbols must be hidden from screen readers using `aria-hidden="true"` once the parent element has a properly provided accessible name (e.g., `aria-label`) to prevent raw ligatures from being read.
**Action:** Always verify that buttons or links which dynamically hide visible text at certain breakpoints include a fallback `aria-label`. Ensure that decorative or structural icons (like `<span class="material-symbols-outlined">`) are given `aria-hidden="true"` whenever their parent provides the accessible name.
