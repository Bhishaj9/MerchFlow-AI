## 2025-05-15 - [ARIA Labels for Icon-Only Interactive Elements]
**Learning:** Icon-only buttons and links utilizing Material Symbols (or any font/SVG-based icons) need explicit `aria-label` attributes to ensure they are accessible to screen readers, especially when text is hidden based on responsive Tailwind classes (like `hidden lg:inline`). Further, the visual icon elements themselves (e.g. `<span class="material-symbols-outlined">`) must have `aria-hidden="true"` so that the screen reader does not read out the raw ligature text (like "arrow_back" or "content_copy") alongside or instead of the label.
**Action:** When adding or auditing icon-based interactive elements (`<button>` or `<a>`), always apply an `aria-label` on the parent interactive element and `aria-hidden="true"` on the child icon element to maintain clean and accessible screen reader output.
