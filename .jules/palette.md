## 2024-05-14 - Responsive Accessibility & Iconography
**Learning:** Elements using responsive utility classes (like `hidden lg:inline`) to hide text on smaller screens lose their accessible name for screen readers on those viewports. Additionally, structural icon fonts (like Google Material Symbols) read out their raw ligature text (e.g., "arrow_back") to screen readers if not explicitly hidden.
**Action:** Always provide an explicit `aria-label` on the parent interactive element (`<button>`, `<a>`) if its text content might be hidden responsively or if it's icon-only. Concurrently, always add `aria-hidden="true"` to structural icon elements (e.g., `<span class="material-symbols-outlined">`) to prevent screen readers from reading the raw ligature text, ensuring the parent element handles the accessible name.
