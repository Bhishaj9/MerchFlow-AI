## 2024-05-07 - Screen Reader Visibility on Responsive and Icon-only Elements
**Learning:** Elements (like buttons or links) that hide their descriptive text on small screens via responsive utility classes (e.g., `hidden lg:inline`), or that exclusively use icon fonts (like Material Symbols), become entirely inaccessible to screen readers if they lack an explicit accessible name. When structural structural icon elements receive `aria-hidden="true"` to prevent raw ligatures from being read, the parent interactive element will lack an accessible name if not explicitly provided one, causing screen readers to completely ignore them or read confusing fallback content.
**Action:** When using icon-only buttons or interactive elements where text is visually hidden on certain breakpoints, always ensure the parent interactive element (`<button>` or `<a>`) has an explicit `aria-label` attribute (e.g., `aria-label="Deploy"`). Additionally, always apply `aria-hidden="true"` to the inner icon element to prevent screen readers from announcing raw ligatures like "rocket_launch".
