## 2026-10-27 - Icon Accessibility on Responsive Buttons
**Learning:** Adding `aria-hidden="true"` to `<span class="material-symbols-outlined">` tags is critical to prevent screen readers from reading raw text ligatures like "rocket_launch" or "content_copy" aloud. However, applying this on responsive buttons where the main text is hidden on small screens via Tailwind classes (e.g., `<span class="hidden lg:inline">Back to Home</span>`) makes the entire interactive element invisible to screen readers on mobile devices unless the parent button has an explicit `aria-label`.
**Action:** When implementing icon-based buttons—especially responsive ones where the visible text label might be conditionally hidden by CSS—always ensure the parent `<button>` or `<a>` tag has a descriptive `aria-label` attribute, and its child icon span has `aria-hidden="true"`.
