## 2025-02-26 - Responsive Icon-Only Button Accessibility
**Learning:** When using responsive classes (like Tailwind's `hidden lg:inline` or `hidden sm:inline-flex`) to hide text inside interactive elements on smaller screens, the parent element (e.g., `<button>` or `<a>`) MUST have an explicit `aria-label`. Otherwise, when the text is visually hidden on mobile devices, the element effectively becomes an icon-only button and is rendered inaccessible to screen readers. If the internal icon ligature (such as Material Symbols) isn't marked with `aria-hidden="true"`, screen readers will erroneously announce the raw font ligature (e.g., "rocket launch") with no context.
**Action:** Always ensure any interactive element that relies on responsive text-hiding techniques has a hardcoded `aria-label` matching its intended accessible name, and mark internal structural icons with `aria-hidden="true"`.
