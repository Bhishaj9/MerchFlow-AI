## 2024-07-24 - Accessible Material Icons on Responsive Buttons
**Learning:** Buttons with text hidden on mobile screens (e.g., using Tailwind's `hidden sm:inline`) and Material Symbol icons (e.g., `<span class="material-symbols-outlined">`) become inaccessible to screen readers on smaller viewports. Additionally, raw icon ligatures (like "arrow_back") might be incorrectly read aloud if not properly hidden.
**Action:** When implementing responsive buttons or using material icons, always apply an explicit `aria-label` attribute to the parent interactive element (`<button>` or `<a>`) to ensure a consistent accessible name across all viewport sizes. Furthermore, add `aria-hidden="true"` to the icon element to prevent screen readers from reading the ligature directly, while ensuring existing `title` attributes remain for native browser tooltips.
