## 2024-05-13 - [Screen Reader Accessibility for Icon-only Buttons & Responsive Hidden Text]
**Learning:** Structural icon elements using Google Material Symbols (like `<span class="material-symbols-outlined">`) must have `aria-hidden="true"` attached to them. Without this, screen readers will mistakenly read out the raw ligature text (e.g., "content underscore copy" instead of ignoring the icon entirely). Also, when using responsive layout classes (like Tailwind's `hidden lg:inline`) to hide descriptive text on smaller screens, the parent interactive element (such as `<button>` or `<a>`) must be given an explicit `aria-label`. Without this, the element becomes completely inaccessible to screen reader users on mobile viewports since the visible text label is hidden.
**Action:** When implementing icon-only interactive elements or elements where text is hidden responsively, ensure the parent has an explicit, descriptive `aria-label` and the inner icon `<span>` or `<svg>` has `aria-hidden="true"`.
